# Inferno Jockey

**Inferno Jockey** is an immersive, mobile-first first-person infinite runner set on the volatile, energy-rich world of **Krneal**. You play as an Inferno Jockey hired to race across harsh terrain, tag raw deposits of **Kytherium** (a natural superconductor), and collect them before environmental collapse catches up to you.

## Core Features
* **Perspective:** First-person view down a fast-paced, industrial-sci-fi corridor.
* **Unique 3D Grid Mechanics:** Built on a 9-lane (3x3) grid where players can only see one full lane and a fractional sliver of neighboring lanes at any time.
* **Tactical Movement:** Navigating across non-adjacent lanes requires calculated multi-step transitions, testing spatial memory and reaction times.
* **Objective:** Dodge geothermal hazards, tag high-energy Kytherium nodes, and survive as long as possible.

## Tech Stack & Architecture
* **Engine:** Unity (Universal 3D / URP)
* **Architecture:** Modular C# scripts built using a Test-Driven Development (TDD) workflow.
* **Target Platforms:** Mobile (iOS/Android) via WebGL (itch.io) prototyping.
